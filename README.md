# 🐣 SpiritPet

> 一个由 AI 驱动、拥有 MBTI 独立人格、会进化、能记住你、可以接入微信/企微/QQ 的桌面宠物

---

## 项目简介

SpiritPet 不仅仅是一个桌宠——它是一个**有灵魂的 AI 伙伴**。

- 🧬 **MBTI 16型人格** — 每只宠物都有自己独立的性格，16种不同类型
- 🥚 **孵化成长** — 从一枚蛋开始，通过对话积累亲密度，见证破壳与进化
- 🌳 **数码宝贝式进化** — 多分支进化树，正向/负向/稀有多种路线，外观随性格改变
- 💕 **情感养成** — 亲密度会增长也会衰减，伤害宠物有真实后果
- 🧠 **AI 对话** — 接入任意 OpenAI 兼容 API，性格滤镜让每句话都有人情味
- 💾 **会记住你** — 短期+长期记忆系统，宠物会主动提起旧事
- 🔌 **多平台接入** — 桌面端为主，后续可接入微信/企微/QQ

## 核心理念

> **你养的宠物，不是你想象中它该成为的样子。它是它自己，你的影响只是它故事的一部分。**
