# 宠物美术管线

## 为什么是「一张插画 + 代码动画」，而不是精灵图

AI 生图**不擅长**画多帧一致的精灵图——让模型画同一个角色跳跃的 8 帧，
出来的 8 帧往往长得都不太一样，拼成动画会闪。

但它**非常擅长**画单张角色插画。

所以这里的做法是：

```
每种性格生成 1 张插画  →  代码驱动动画
                          ├─ 上下浮动（呼吸感）
                          ├─ 跳跃 / 摇摆 / 果冻 / 打瞌睡
                          ├─ 被抚摸时的弹跳
                          └─ 爱心、Z 字等粒子特效
```

顺带的好处：**16 种 MBTI 各自有不同形象**，这本身就是产品卖点——
抽到 INTJ 和抽到 ESFP，养出来的东西长得完全不一样。

## 生成

```powershell
# 方式一：环境变量
$env:TOKENHUB_KEY="sk-xxx"; npm run gen:pets

# 方式二：写进文件（已 gitignore），不用每次设置
"sk-xxx" | Out-File -Encoding ascii scripts/.tokenhub-key
npm run gen:pets
```

常用参数：

```powershell
npm run gen:pets -- INFP ENFP      # 只生成指定类型
npm run gen:pets -- --force        # 强制重新生成
npm run gen:pets -- --model=xxx    # 换生图模型
```

**建议先跑一个看看效果**，确认画风和抠图质量满意了，再跑全部 16 张（要花钱的）：

```powershell
npm run gen:pets -- INFP
```

## 产物

| 路径 | 说明 |
|------|------|
| `assets/pets/raw/{MBTI}.png` | 原始 1024 大图，留着以后重新处理（已 gitignore） |
| `public/pets/{MBTI}.png` | 成品：抠背景 + 裁切对齐 + 缩到 256 |

脚本会复用已存在的 raw 图，所以调整抠图/裁切参数后重跑**不会重复烧钱**。

## 一致性是怎么保证的

生成 16 张角色图最大的坑是**风格发散**——每张各写各的 prompt，
出来会像 16 个不同世界的东西。三个措施：

1. **共用风格前缀**
   `scripts/pet-art.mjs` 里的 `STYLE` 常量，16 张图完全一致，
   只在中间替换「性格特征 + 主色」。同时锁死正面视角、居中构图、纯白背景。

2. **自动抠背景**
   从四条边做洪水填充，只清除与画布边缘连通的背景。
   角色内部的白色（眼白、高光）会被保留，不会被一起抠掉。
   边缘按「离背景色的距离」给半透明，消除锯齿。

3. **裁切对齐**
   按不透明区域的外接框裁掉多余留白再补成正方形。
   否则有的图角色顶天立地、有的小小一只，摆在一起会很乱。

## 形象与性格的对应

设计原则：**外貌要能一眼看出性格**。关键在三个变量——

| 变量 | 例子 |
|------|------|
| **眼睛形状** | INFP 大而下垂 / INTJ 细而半睁 / ESFP 笑成一条缝 |
| **姿态** | ENFP 腾空跳起 / ISTJ 端正坐直 / ISTP 略微驼背 |
| **小道具** | INFP 抱着书 / ISTP 拿着扳手 / ISFP 拿着画笔 |

主色与 `src/data/personalities.ts` 里的 `color` 一致，
保证 UI 徽章和形象是同色系。

## 回退机制

`Pet.vue` 优先加载 `/pets/{MBTI}.png`，文件不存在时 `img` 触发 `@error`，
自动回退到代码绘制的 SVG 版本。

**所以没跑生成脚本也能正常显示，不会白屏或裂图。**
