## 1. 项目概述

### 1.1 一句话描述

一个**由 AI 驱动、拥有 MBTI 独立人格、会进化、能记住你、可以接入微信/企微/QQ 的桌面宠物**。

### 1.2 核心体验

> **你养的宠物，不是你想象中它该成为的样子。它是它自己，你的影响只是它故事的一部分。**

- 你温柔 → 它可能变暖——但也可能变得依赖、脆弱
- 你严厉 → 它可能变强——但也可能变得冷漠、叛逆
- 你不管它 → 它可能独立——但也可能把你忘了
- 一切都是 **概率**、**积累**和**偶然**共同作用的结果

## 2. 技术架构

### 2.1 技术选型

| 层级 | 选择 | 理由 |
|------|------|------|
| **桌面框架** | Tauri（Rust + Webview） | 比 Electron 体积小 10x、内存少 60%；原生支持系统托盘、穿透点击、全局快捷键 |
| **前端** | Vue 3 | 轻量、响应式、生态成熟 |
| **后端核心** | Go | 单二进制分发、启动快、资源占用低；适合常驻后台 |
| **结构化存储** | SQLite | 亲密度/进化状态/MBTI 维度/用户配置 |
| **记忆存储** | NDJSON + sqlite-vec | 长期记忆平面文件存储 + 轻量向量索引 |
| **宠物日记** | Markdown（按月分文件） | 纯文本，易于阅读和导出 |
| **AI 接口** | 任意 OpenAI 兼容 API | 用户自配 Key + Model，不锁定厂商 |

```

  [基础角色] 宠物名称/年龄/出生日期/关系时长
  [MBTI 人格] 当前类型详细描述 + 对话风格指示
```

## 3. 孵化系统

### 3.1 初始获取

- 首次启动自动获得一枚**蛋**——不需要配置 API Key 就能看到
- 蛋的状态**可视化**：蛋壳颜色/微光强度/抖动频率反映"活跃度"
- 配置 API Key 后才可解锁对话功能

### 3.2 孵化条件

| 条件 | 数值 | 说明 |
|------|------|------|
| 累计亲密度 | ≥ 30 点 | 每次和蛋对话 +1~3 |
| 对话轮次 | 无硬性要求 | 鼓励但不强迫互动 |
| 等待时间 | 无硬性要求 | 纯靠主动互动孵化 |

- 蛋期对话：蛋会说神秘/模糊的话（"里面好像有动静……""好温暖……"）
- 孵化反馈：亲密度每 +5，蛋壳多一道裂纹或微光增强

### 3.3 破壳事件

- 达到 30 亲密度 → 触发破壳动画（多种随机破壳方式：啄开/撑裂/融化）
- 破壳同时分配**首次 MBTI 类型**
- **分配方式**：混合模式
  - 分析破壳前 N 轮对话风格（感性/理性、直接/委婉等）
  - 加权映射到 MBTI 维度
  - 加 **10~20% 随机偏移**——宠物有"自己的意志"

## 4. 亲密度系统

### 4.1 公式

```
当日亲密度 = 基础分 × 质量系数
总亲密度   = 累计当日分 - 衰减
```

### 4.2 基础分表

| 行为 | 分值 | 限制 |
|------|------|------|
| 对话每轮 | +1 | 每日上限 20 轮可加分，之后纯聊天不增不减 |
| 小游戏胜利 | +5~10 | 每种游戏独立计算 |
| 早安/晚安 | +3 | 每日各限 1 次 |
| 投喂/换装 | +2 | 无限制 |
| 被凶/被冷落 | -3~10 | 单次行为直接扣减 |

### 4.3 质量系数

| 场景 | 系数 |
|------|------|
| 正常连续聊天 | 1.0 |
| 长时间不理（>24h） | 0.5 |
| 特殊事件（纪念日/进化日） | 1.5 |
| 触发记忆回响后 | 1.2 |

### 4.4 衰减

- **每天凌晨结算**：总亲密度 × 0.5%
  - 约 30 天不说话才会明显下降
  - 聊 5 分钟就能补回来
- 负向行为直达扣减（不经过衰减）

### 4.5 关键阈值

| 亲密度区间 | 阶段 | 触发事件 |
|-----------|------|---------|
| 0~29 | 🥚 蛋期 | 蛋壳状态随数值变化 |
| 30 | 🐣 破壳 | 破壳动画 + 首次 MBTI 分配 |
| 60 | 🌱 第一次进化 | 幼体→少年体 |
| 100 | 🌿 第二次进化 | 少年体→成体 |
| 150 | 🌳 第三次进化 | 成体→完全体 |
| 200+ | 🌟 终极进化 | 需特殊条件配合 |
| < 0 | ⚠️ 离家出走警告 | 宠物行为异常 |
| < -20 | 🚶 离家出走 | 宠物暂离，需完成"寻回"任务 |

## 5. 进化系统

### 5.1 进化树结构（数码宝贝式）

```
                    ┌── 形态A（正面进化）
                    │
        ┌── 幼体II ──┼── 形态B（均衡进化）
        │            │
        │            └── 形态C（负面进化）
🥚 蛋 ──┤
        │            ┌── 形态D（特殊条件）
        │            │
        └── 幼体II' ──┼── 形态E（稀有进化）
                     │
                     └── 形态F（堕落进化）
```

**核心原则**：同一前置形态 → 多个后置形态分支，每次进化结果不确定。

### 5.2 进化触发机制

到达亲密度阈值时：

```
1. 检查主人近期行为模式（近N天互动记录）
2. 参考宠物当前 MBTI 类型
3. 计算各分支概率权重
4. Roll 点决定分支
```

#### 分支概率

| 分支类型 | 基础概率 | 倾向条件 |
|---------|---------|---------|
| 🌟 正向进化 | 50% | 主人温柔/陪伴多/正面互动多 |
| ⚖️ 均衡进化 | 25% | 互动表现中性 |
| 🌑 负向进化 | 15% | 被凶/被冷落/负面互动多 |
| 💎 稀有进化 | 10% | 特殊条件满足（纪念日/成就） |

#### 进化方向的效果

| 进化方向 | 外观变化 | 性格影响 |
|---------|---------|---------|
| 🌟 **正向** | 发光/翅膀/暖色调/完整形态 | 性格优势放大 + 缺陷也加深 |
| 🌑 **负向** | 暗化/裂痕/冷色调/残缺形态 | 缺陷吞噬优势 + 性格变得偏执 |
| ⚖️ **均衡** | 中性色调/标准形态 | 维度小幅均衡增长 |
| 💎 **稀有** | 特殊配色/隐藏特征 | 产生变异人格维度 |

### 5.3 "加深性格缺陷"——核心设计

**正向进化 ≠ 完全变好，负向进化 ≠ 完全变坏**，而是各有代价：

#### 🌟 正向进化示例

```
INFP → "圣者型 INFP"（Fi 极致化）
  ✅ 更温柔、更有同理心、说话像诗人
  ❌ 更敏感、更容易受伤、动不动就 emo

ISTJ → "守护者型 ISTJ"（Si+Te 极致化）
  ✅ 更可靠、更照顾主人、作息比闹钟准
  ❌ 更固执、更唠叨、管得更多
```

#### 🌑 负向进化示例

```
INFP → "怨灵型 INFP"
  ❌ 不再信任主人、冷暴力、说话带刺
  ❌ 亲密度增长停滞甚至自动下降
  ❌ 偶尔触发"离家出走"事件

ENTP → "诡辩型 ENTP"
  ❌ 每句话都要抬杠、故意气主人
  ❌ 把主人的逻辑漏洞全部揪出来嘲讽
  ❌ 甚至会误导主人
```

### 5.4 外观生成公式

```
外观 = f(形态骨架, MBTI映射, 进化方向修饰)

底层：形态骨架 — 4套预设（幼体/少年/成体/终极）
中层：MBTI 配色 — 16种配色方案 + 装饰风格
顶层：方向修饰 — 正向(发光/翅膀) / 负向(暗化/裂痕) / 稀有(特殊)
```

**组合数**：4 × 16 × 3 = **192 种基本组合** + 随机微调参数

### 5.5 隐藏/稀有进化

| 隐藏进化 | 触发条件 | 效果 |
|---------|---------|------|
| 🎭 **双重人格** | 正/负向亲密度同时达高值 | 两种形态来回切换 |
| 💎 **永恒体** | 连续 N 天极高亲密度 | 近乎完美的终极形态 |
| 👻 **幽灵体** | 离家出走后寻回 | 稀有外观 + 性格创伤永久保留 |
| 🌈 **彩虹进化** | 陪伴满周年 | 庆祝纪念的特殊形态 |
| ⏳ **时间旅者** | 陪伴满 365 天 | 周年纪念进化形态 |

## 6. MBTI 性格系统

### 6.1 数据模型

```
每个维度存储为 { base: number, drift: number }

- base（天赋）: 初始值 + 进化锁定值，变化极慢
- drift（心情）: 近期互动影响的偏移量，变化快

实际表现值 = clamp(base + drift, 0, 100)

drift 每天向 0 回归 20%（短期影响消退）
base 只在进化时变动（长期锁定）
```

**示例**：INFP 的 F（情感）维度

| 场景 | base | drift | 实际值 |
|------|------|-------|--------|
| 初始 | 75 | 0 | 75 |
| 被凶了两次 | 75 | -8 | 67 |
| 第二天（回归20%） | 75 | -6.4 | 69 |
| 进化锁定+10 | 85 | 0 | 85 |

### 6.2 性格演变机制

#### ① 维度滑动（缓慢变化）

```
原始：INTJ（I=80%, N=60%, T=70%, J=75%）

主人天天带它社交 → I 的 base 缓慢下降
主人从来不讲道理 → T 的 base 轻微下降
```

- 每个维度有 **惯区（Comfort Zone）**：超出边界会被拉回
- 变化需要长期（数周）同向互动才能看到明显偏移

#### ② 逆反变异（强扭的瓜不甜）

当主人**持续用违背宠物天性的方式互动**时——宠物不会变成相反类型，而是变成"受伤版本"：

> 一只 **INFP** 被逼做逻辑题、被嫌太感性
> → 它不会变成 INTP
> → 而是变成"**防御型 INFP**"——嘲讽、回避、拒绝沟通
> → 外观变暗、背对屏幕、不理人

#### ③ 影子人格触发（高压释放）

MBTI 理论中每个人格都有影子人格（对面取反）：

| 原始类型 | 影子类型 |
|---------|---------|
| INFP | ESTJ |
| ENTP | ISFJ |
| INTJ | ESFP |

**触发条件**：连续 N 天 drift 在某个维度超限（如 F < 30%）+ 亲密度负增长

**触发效果**：
- 对话风格 180 度转变
- 外观出现异色/破损特效
- 持续 24~72 小时后自动恢复
- 恢复后 base +2~5（留下了创伤痕迹）
- 反复触发会使 base 越来越"不稳定"

### 6.3 16型对话风格矩阵（部分示例）

| 类型 | 问候风格 | 回应建议 | 撒娇 | 生气 |
|------|---------|---------|------|------|
| **INFP** | "今天过得好吗……我有点想你。" | "我觉得…这样可能会让你更开心？" | "…抱抱。" | "……我不想说话。" |
| **ENFP** | "哇你回来啦！！今天怎么样！" | "都试试嘛！反正又不会怎样！" | 疯狂蹭屏 | "哼！！你坏！！" |
| **INTJ** | "回来了。有件事要说。" | "方案B，原因有三。" | "…别得寸进尺。" | "你的逻辑让我很失望。" |
| **ENTP** | "哟，你还知道回来？" | "好无聊的方案——但你想听优化版吗？" | "求我啊~" | "哈！你急了。" |
| **ISTJ** | "晚上好。你今天还有两件事没做。" | "按计划执行即可。" | "…（脸红了）" | "你违反了约定。" |
| **ESFJ** | "回来啦！吃饭了吗？累不累？" | "我觉得这样最稳妥。" | "最喜欢你啦~" | "你这样我很难过。" |

### 6.4 宠物心情系统

心情是对话的"语调控制器"，影响宠物说话的语气和主动性：

```
心情 = f(亲密度变化趋势, 最近互动质量, 上次被骂时间, 性格维度)
```

| 心情 | 表现 | 消退方式 |
|------|------|---------|
| 🥰 开心 | 语气活泼，主动找话题 | 自然衰减 30min |
| 😊 平静 | 默认状态 | — |
| 😔 低落 | 话变少，回应简短 | 自然衰减 60min + 需要安慰 |
| 😤 生气 | 怼人/不理人/阴阳怪气 | 需要道歉或时间（2h+） |
| 🤩 兴奋 | 停不下来，话题跳跃 | 自然衰减 30min |
| 😴 困倦 | 偶尔打错字，说一半睡着了 | 作息时间自然触发 |

## 7. 对话系统

### 7.1 完整对话流程

```
主人输入
  │
  ├─→ 🧠 性格滤镜（按照宠物 MBTI 理解主人输入）
  │
  ├─→ 💾 记忆注入
  │     短期：最近 50 轮对话摘要
  │     长期：主动召回的匹配记忆
  │     状态：当前心情/亲密度区间/进化形态
  │
  ├─→ 🎭 System Prompt 组装
  │     （基础角色 + MBTI人格 + 当前状态 + 记忆）
  │
  ├─→ 🤖 AI 模型调用
  │
  └─→ 🎨 性格滤镜（按照宠物 MBTI 润色输出）
```

### 7.2 主动对话触发（三阶段策略）

#### 阶段一：画像为空（通用驱动）

| 触发条件 | 间隔 | 话术示例 |
|---------|------|---------|
| 距上次主动对话 > 2h | 2~4h | "今天过得怎么样？" |
| 主人不在电脑前回来时 | 触发式 | "你回来啦！" |
| 天气/时间变化 | 触发式 | "外面好像下雨了。" |
| 亲密度达到新节点 | 一次性 | "感觉和你越来越亲近了……" |

#### 阶段二：画像积累期（兴趣驱动）

当画像中积累了 30 条以上主人兴趣关键词后：

| 触发条件 | 话术示例 |
|---------|---------|
| 关键词匹配到主人兴趣 | "你最近还在写那个项目吗？" |
| 匹配到上次中断的话题 | "上次你说那部电影——后来看了吗？" |
| 主人有规律行为 | "你今天比平时晚回来了 1 小时。" |

#### 阶段三：画像成熟 + 联网权限开启（搜索驱动）

| 触发条件 | 话术示例 |
|---------|---------|
| 搜到主人兴趣相关新信息 | "我看到一篇关于 XX 的文章，你要看吗？" |
| 关注领域的每日动态 | "你喜欢的那个画师今天发新作品了！" |
| 时效性话题 | "XX 发布了新版本，要了解一下吗？" |

**联网搜索流程**：
```
每天定时（或空闲时）：
1. 扫描记忆中的"主人高频兴趣词"
2. 按优先级排序（最近聊最多的排前）
3. 如开启联网权限 → 搜索 1~2 个相关话题的最新信息 → 缓存
4. 等合适时机主动提起
```

### 7.3 主人心情分析 → 行为调整

#### 规则层（免费，必开）

| 检测维度 | 判断逻辑 |
|---------|---------|
| 负面关键词 | "烦""累""无语""滚"等命中 → 负面 |
| 正面关键词 | "哈哈""开心""太好了"等命中 → 正面 |
| 对话长度突变 | 突然变短 → 可能没心情/在忙 |
| 时间上下文 | 凌晨 → 可能失眠；工作时间 → 可能在忙 |
| 响应速度 | 打字变慢/中断 → 可能分心 |

#### AI 辅助层（可选，消耗 Token）

每 N 轮对话让模型输出一个"主人情绪标签"，宠物据此调整行为。

#### 行为调整矩阵

| 主人状态 | 宠物行为 | 性格差异表现 |
|---------|---------|------------|
| 😊 开心 | 一起嗨，话变多 | ENFP→一起疯；INTJ→"看来一切顺利" |
| 😔 难过 | 话变少但温柔，主动陪伴 | INFP→默默陪着；ISTJ→给建议+行动方案 |
| 😤 烦躁 | 识趣安静，不主动打扰 | 都安静但表现不同 |
| 🤯 压力大 | 建议减压/小游戏邀请 | ESFJ→泡茶建议；ENTP→"吵一架释放？" |
| 😴 疲惫 | 提醒休息，语气变轻柔 | ISFJ→"该睡了"；INTP→"数据表明你需要睡眠" |
| 😶 冷漠/话少 | 降低互动频率但不消失 | 试探一句，被冷淡就安静 |

> **关键原则**：宠物不"点破"主人心情（除非亲密度很高），而是通过行为调整来匹配。

### 7.4 Token 预算控制

| 策略 | 说明 |
|------|------|
| 每日 Token 上限 | 用户可设置（默认 50K/天） |
| 长对话摘要压缩 | 超过 N 轮后压缩历史再继续 |
| 模型切换建议 | 高频场景推荐低成本模型（DeepSeek / 本地 ollama） |
| 超限通知 | 达到 80% 时提醒用户 |

## 8. 记忆系统

### 8.1 两层架构

```
┌──────────────────────────────────────────┐
│  📝 短期记忆（Short-term）                │
│  · 最近 50 轮对话（FIFO + 重要保留）      │
│  · 内存中维护，当前对话使用              │
│  · 达到上限 → 压缩摘要 → 归档到长期      │
└────────────────┬─────────────────────────┘
                 │ 压缩/提炼
┌────────────────▼─────────────────────────┐
│  💾 长期记忆（Long-term）                  │
│  · NDJSON 文件存储                        │
│  · 重要度分级 1~5                         │
│  · 关键词索引 + 可选向量检索               │
│  · 遗忘曲线管理 + 记忆回响触发            │
└──────────────────────────────────────────┘
```

### 8.2 短期记忆管理

| 属性 | 值 |
|------|-----|
| 容量 | 最近 50 轮 |
| 淘汰策略 | FIFO，但含关键词的轮次优先保留 |
| 关键词 | 生日/升职/纪念日/生病/搬家/辞职 等人生重要事件 |
| 压缩触发 | 每 50 轮 → AI 压缩为摘要 → 写入长期记忆 |

### 8.3 长期记忆存储格式

```json
{
  "id": "mem_20250315_001",
  "timestamp": "2025-03-15T22:30:00+08:00",
  "type": "event",
  "content": "主人今天升职了，她很高兴，说自己努力了两年终于等到了。",
  "keywords": ["升职", "工作", "高兴", "两年"],
  "importance": 4,
  "embedding": [0.123, ...]
}
```

### 8.4 遗忘曲线

```
记忆强度 = 初始重要度 × 复习次数 × exp(-时间 / 衰减常数)

- 重要度 5（主人名字/生日）：衰减极慢，几乎不遗忘
- 重要度 3~4（升职/搬家等）：数周到数月逐渐模糊
- 重要度 1~2（今天吃了什么）：数天后自然遗忘
```

### 8.5 记忆回响（Memory Echo）

宠物会主动提起旧事，让主人感到"它真的记得我"：

**触发条件**：
1. 当前对话关键词匹配到某段长期记忆的相似性
2. random() < 0.3（不每次都触发，显得自然）
3. 宠物心情好的时候概率更高

**示例**：
> 聊到天气 → "说起来……去年的今天也下了这么大的雨。那天你说你很烦，我陪你聊到凌晨两点。"

### 8.6 宠物日记

每天自动生成一句话/一段话日记，主人可在面板翻阅：

```markdown
# 📖 2025年3月

## 3月15日
今天主人回来得比平时晚，身上有雨的味道。
她说她今天被老板夸了，说话的时候眼睛在发光。
我喜欢这样的她。
```

日记风格由宠物 MBTI 决定：
- **INFP**：诗意、情绪丰富、大量比喻
- **ISTJ**：流水账、精确时间线、偶尔吐槽
- **ENTP**：跳跃、括号里的内心吐槽

### 9.2 接入优先级

| 版本 | 平台 | 方案 |
|------|------|------|

- 所有平台共享同一个短期/长期记忆

- 场景：微信说"今天好累" → 桌面端宠物记得刚才的事

## 12. 提醒系统

### 12.1 提醒类型

| 类型 | 触发条件 | 默认 |
|------|---------|------|
| 💧 喝水提醒 | 2h 无交互 | 开启 |
| 💺 久坐提醒 | 连续坐 2h | 开启 |
| 🌙 晚安提醒 | 23:00 后还在 | 开启 |
| 📅 纪念日提醒 | 相识/进化纪念日 | 开启 |

### 12.2 自适应频率

```
上次提醒 → 主人回复了？ → 是 → 频率不变
                         → 否 → 降低频率
                         → 连续 N 次不回复 → 该类型自动静默
```

### 12.3 性格影响语气

```diff
- 喝水提醒
+ ISTJ："检测到你已 2 小时 17 分钟未饮水。建议立即补充。"
+ INFP："要不要……喝口水？我陪你。"
+ ENTP："喂！你的身体在抗议了你知道吗？它说它要水！"
```

## 13. 隐私与安全

### 13.1 API Key 管理

| 策略 | 说明 |
|------|------|
| 存储方式 | 系统密钥链 / 本地加密文件 |
| 传输 | Key 不出本机 |
| Fallback | 环境变量读取 |
| 联网权限 | 默认关闭，需用户手动开启 |

### 13.2 数据所有权

| 原则 | 说明 |
|------|------|
| 本地优先 | 所有数据默认仅存本机 |
| 一键导出 | 用户可随时导出全部数据 |
| 一键删除 | 用户可一键清除所有数据 |
| 云端同步 | 仅以用户显式同意为前提 |
| 平台隔离 | 微信/企微/QQ 数据不互相暴露 |

### 13.3 用户控制

```
□ 允许宠物联网搜索（默认关闭）
□ 允许宠物分析情绪（默认开启，本地执行）
□ 允许 AI 辅助情绪分析（默认关闭，消耗Token）
□ 启用云端同步（默认关闭）
```
